Does your app collect or share user data?
YES — collected on YOUR game server, not by Google.

Collected (app functionality, not sold, not used for ads):

• Name (player nickname) — Account
• Password (hashed) — Account
• Parent email (optional / signup) — App functionality (stop-play review email)
• Game progress (coins, stars, unlocks, likes, chat on this server) — App functionality
• Approximate activity (play session words/mistakes) — App functionality

Not collected:
• Location, contacts, photos, files, calendar
• Advertising ID
• Precise location

Microphone: used only in the browser when the player taps “Say it”. Audio is not uploaded to Google. Speech stays on the device for recognition unless the browser sends it to the OS speech service.

Sharing: not sold. Chat messages are visible to other players on the same Word Stars server.

Security: data is in transit via HTTPS if you host with HTTPS. Passwords are hashed.

CONFIRMED FROM CODE:
"Say it" (static/js/game.js, space.js) uses the browser's built-in
window.SpeechRecognition / webkitSpeechRecognition API. Only the
recognized TEXT is read by our JS — no audio is ever POSTed to the Flask
server. HOWEVER: on Chrome/Android, webkitSpeechRecognition itself sends
the raw microphone audio to Google's cloud speech-recognition service to
be transcribed (this is a Chrome/OS behavior, not something this app's
code controls). So for Data Safety, answer:
  - "Does your app collect audio?" -> mic audio is captured and sent to
    Google's speech recognition service by the browser/OS, not stored or
    seen by our own server.
  - Purpose: App functionality (voice practice), not shared for ads,
    not sold.
